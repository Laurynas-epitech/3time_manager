# Project progress tracking

Read `MEMORY.md` before project work and follow its status legend, project scope and persistent user decisions.

After every implementation, verification, deployment or planning task, update the affected checklist entries in `MEMORY.md`, describe completed and remaining work, cite dated evidence, recalculate totals when statuses change, and add a short progress-log entry. If no requirement changed, record that without changing its completion status.

Only fully verified requirements receive `[x] [PASS]`. Keep partial, missing, unverified, not-applicable and deferred work distinct. Keep mandatory criteria separate from bootstrap-specific, recommended and optional items. Do not apply deferred HTTPS changes without renewed user authorization.

Follow any additional instructions in nested `AGENTS.md` files for the files being edited.
